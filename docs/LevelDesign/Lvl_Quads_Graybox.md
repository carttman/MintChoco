## 3. 벽 구조 (설계서와 달라진 부분)

설계서 §9.2의 ASCII와 §9.4 배치표가 서로 다른 개구부를 그리고 있어,
**실제로 걸어서 성립하는 쪽으로 확정**했다.

- 십자 커넥터 4개: 폭 800 (`|x| ≤ 400` 남북 / `|y| ≤ 400` 동서)
- 커넥터 양옆 벽: 각 변마다 300짜리 2조각 + 그 사이 **400 폭 병목**
  (예: x=−400 라인의 병목은 y ∈ [−1100, −700])
- 벽은 y=±1400 / x=±1400에서 끝나 **폭 600의 외곽 순환 링**이 열려 있다

결과적으로 각 사분면의 출입구는 **병목 2개 + 외곽 링 2개 = 4개**이고,
스폰에서 상대 스폰까지 3개 경로(중앙 십자 / 좌 링 / 우 링)가 성립한다.

> 처음에는 벽을 1000짜리 통짜로 두었더니 왕복이 **16.9초**로 나왔다(목표 10~12초).
> 벽 가운데를 400 뚫어 대각 진입을 열자 **11.1초**가 됐다. 벽을 다시 만질 때는
> 반드시 §5의 동선 측정을 다시 돌릴 것.

## 5. 동선 재측정 방법

지오메트리를 고친 뒤에는 아래 경로를 `SceneTools.trace_world`로 다시 재고,
합계를 400으로 나눠 10~12초 안에 들어오는지 확인한다.

```
(-1400,-1400) → (-1117,-1117) → (-834,-834) → (-400,-900) → (0,0)
             → (400,900) → (834,834) → (1117,1117) → (1400,1400)
```

## 6. 실제 오브젝트로 교체하는 순서

태그별로 골라 1:1 치환한다. **위치·회전·스케일은 그대로 두고 메시만 바꾸면 된다.**

| 순서 | 대상 | 교체 내용 |
|---|---|---|
| 1 | `GB_JumpPad` ×4 | `BP_JumpPad`(미구현)로 치환. 마커의 위치가 곧 점프대 위치, 착지 목표는 중앙 플랫폼 |
| 2 | `GB_ItemBox` ×2 | `BP_ItemBox`(미구현)로 치환 |
| 3 | `GB_InitialPaint` ×2 | `BP_InitialPaintVolume`(미구현)로 치환. 설계서 §4.4 — `SplatVolume 64` 스플랫 **1발** |
| 4 | `GB_Ramp` ×2 | **현재는 pitch를 준 박스**다. 페인트를 붙이려면 설계서 §2.3의 "Yaw만 회전" 규칙 때문에 **기울어진 윗면을 가진 웨지 메시**로 다시 만들어야 한다 |
| 5 | `GB_Floor`, `GB_Spawn` | Modeling Mode 모듈(UV1 + Nanite off) + `APaintableActor` 상속 BP로 치환. RT 해상도는 설계서 §2.2 |
| 6 | `GB_Wall`, `GB_Bound`, `GB_Cover` | 비페인터블 유지. 아트 메시로만 교체 |

## 7. 남은 확인 사항

1. **캐릭터 세팅이 아직 176cm 기준이다.** 설계서 §1.1(캡슐 75/30, JumpZVelocity 600,
   GravityScale 1.5, MaxStepHeight 40)과 부록 A-3(SpawnClearance 75/30)을 적용하기
   전까지, 중앙 플랫폼(높이 100)을 점프로 오를 수 있는지 등 **높이 문법이 검증되지
   않은 상태**다. 이것부터 맞춘 뒤 플레이테스트할 것.
2. **아이템 박스 R6 편차**: 피킹 엄폐 하나가 `(−800,+800)`으로 아이템 박스에서
   566cm다(R6는 700 이상 개방 요구). 사분면이 1550² 밖에 안 돼 700 개방과
   R1(엄폐 600 이내)을 동시에 만족시킬 수 없다. 플레이테스트에서 아이템 지점이
   너무 안전하게 느껴지면 이 엄폐물을 먼저 뺄 것.
3. **에디터 뷰포트가 직교(Front) 모드**라 평면도 캡처가 되지 않는다. 원근 뷰로
   바꾸면(뷰포트 좌상단 뷰 타입 메뉴 또는 단축키) 전체 레이아웃이 보인다.
4. 저격 사거리는 설계서 부록 B(`MuzzleSpeed 6000 / GravityScale 0.1`)를 적용해야
   이 맵의 장거리 사격선(소고지 ↔ 중앙 2000cm)이 성립한다.
